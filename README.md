# Awesome Kimi Code CLI

*Unofficial community list for Kimi Code CLI. Not affiliated with Moonshot AI. All trademarks belong to their owners.*

A curated list of resources for Kimi Code CLI, the terminal form of Moonshot AI's Kimi Code coding agent, and for the Kimi API Platform pages you need when you run it with your own key. Only links that the Kimi Code page, the platform docs or the launch coverage actually contain are included.

> No codebase yet? [Begin.sh - turn a prompt or a URL to clone into a static site or Expo app, download the zip](https://begin.sh?utm_source=github&utm_medium=ugc&utm_campaign=awesome-kimi-code-cli&utm_content=readme-top&utm_term=tier-r).
